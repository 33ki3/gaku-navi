# プロダクト UI 仕様

該当機能を変更するときだけ参照し、実装とテストが異なる場合は現在のコードを確認して差異を解消する。

## カード検索とフィルター

- キーワードはカード名、Pアイテム名、スキルカード名、イベントタイトルへ部分一致し、リアルタイム反映する。
- レアリティ、タイプ、プランなどはカテゴリ内 OR、カテゴリ間 AND。
- 凸数は 0〜4凸の OR 条件。アビリティとイベント種別はそれぞれ2カテゴリで、カテゴリ間 AND、カテゴリ内 OR。
- フィルター状態は localStorage へ保存し、リロード時に復元する。
- active / inactive の border 幅を揃え、リセットはフィルター有効時に表示する。

## カード一覧と詳細

- 一覧はレスポンシブなグリッドと仮想スクロールを使う。
- 一覧には主要バッジ、イベント概要、スコア、アビリティバッジを表示し、詳細情報はモーダルへ分ける。
- 詳細モーダルはイベント、アビリティ、Pアイテムを表示し、各セクションを折りたためる。
- 0〜4凸セレクタはモーダル内で即時反映し、モーダルローカル状態とする。一覧側のカード別凸数は localStorage に保存する。
- 凸数変更だけでは一覧の並び順を変えない。スコア設定変更時に再ソートする。

## 並び替え

- レア度順: レア度降順、次に新着順。
- 新着順: 登場日降順、次にレア度降順。
- 点数順: 計算スコア降順。
- 凸数順: 凸数昇順、次にレア度降順、新着順。
- 逆順トグルで順序を反転する。

## 点数設定

- PC は固定可能なパネル、モバイルはオーバーレイ。
- パラメータボーナスは Vo / Da / Vi を分け、内訳を確認できる。
- シナリオ、難易度、スケジュールは `src/data/score/schedule.ts` を正本とする。
- 計算ロジックは `src/utils/calculator/` を正本とし、UI に複製しない。
- スコア内訳は0点を含む全アビリティを表示し、効果名をスクロール可能、点数を右側へ固定する。

## 既存の保存キー

- 点数設定: `gaku-navi-score-settings`
- カード別凸数: `gaku-navi-card-uncaps`

保存形式やリセット UI を変更するときは、import / export と既存データ移行も確認する。
